    Connections

    Connect Instagram only · no Facebook Page

    In your Meta app, open Instagram → API setup with Instagram Login. Add your Business account and generate an Instagram User token with instagram_business_basic and instagram_business_content_publish.

    Paste the token here, not in chat. It is sent only to the local service and Meta for a read-only profile check, then stored privately on this computer. No post is created. This first version uses a dashboard-generated token, not a hosted OAuth sign-in.

    Profile verification does not prove publishing permission. Check token expiry in Meta; automatic renewal is not configured.
